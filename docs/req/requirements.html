System Requirements - Bacalyze

System Requirements for Windows

  • Windows 10: 64-bit, version 22H2 (build 19045) or higher.
  • Windows 11: 64-bit, version 22H2 or higher.
  • Windows Subsystem for Linux (WSL) 2 enabled.
  • Hardware virtualization enabled in BIOS.
  • 12 GB RAM (16 GB recommended)
  • Atleast 10 GB free disk space

System Requirements for Linux (To run natively)

  • 64-bit Linux Operating System
  • 8 GB RAM (16 GB recommended)
  • Atleast 10 GB free disk space
  • There are additional dependencies accessible by clicking here if you want Bacalyze to run natively on Linux.

System Requirements for Linux (To run inside Docker)

  • 64-bit Linux Operating System
  • Docker installed
  • 12 GB RAM (16 GB recommended)
  • Atleast 10 GB free disk space
  • Please refer to the official Docker documentation for more details on setting up Docker in your linux distribution.

System Requirements for macOS

  • Supported macOS version (Intel or Apple Silicon)
  • 16 GB RAM (Intel)
  • 12 GB RAM (Silicon Mac)
  • Atleast 10 GB free disk space
