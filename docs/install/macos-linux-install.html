macOS and Linux (Docker) Installation - Bacalyze

Follow the steps below to install Bacalyze on macOS:

  1. Download the archive file from the Github releases page.
  2. Install docker desktop for mac from here.
  3. Extract the archive into ~/Documents/Bacalyze. Create the folder if necessary
  4. Make sure the directory structure is ~/Documents/Bacalyze/DockerFile/.
  5. Open a terminal inside the ~/Documents/Bacalyze/DockerFile/ directory.
  6. Run docker build -t kani .. Note: Include the period (.) at the end.

If you encounter any issues during installation, please refer to the Requirements page to ensure your system meets the minimum requirements.

Contact Support for Installation Issues in macOS

Follow the steps below to install Bacalyze on Linux inside Docker environment:

  1. Install docker for linux. Please refer to docker's documentation to install according to their instructions for your specific linux distribution.
  2. Configure docker to run without sudo. This is necessary to prevent permission issues, and to make sure that the pipeline is accessing your documents directory.
  3. Download the archive file from the Github releases page.
  4. Extract the archive into ~/Documents/Bacalyze. Create the folder if necessary
  5. Make sure the directory structure is ~/Documents/Bacalyze/DockerFile/.
  6. Open a terminal inside the ~/Documents/Bacalyze/DockerFile/ directory.
  7. Run docker build -t kani .. Note: Include the period (.) at the end.

If you encounter any issues during installation, please refer to the Requirements page to ensure your system meets the minimum requirements.

Contact Support for Installation Issues in Linux
