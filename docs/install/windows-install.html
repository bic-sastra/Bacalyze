Windows Installation - Bacalyze

Follow the steps below to install Bacalyze on Windows:

  1. Download the latest release from the Github release page.
  2. Extract the downloaded zip file to a directory of your choice.
  3. Open a command prompt as administrator and navigate to the extracted directory.
  4. Run the installation script by typing install.bat and pressing Enter.
  5. Follow all the instructions given in the command prompt.

Once the installation is complete, you can start using Bacalyze.
