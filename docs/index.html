Welcome to Bacalyze

What is Bacalyze?

Bacalyze is a bioinformatics pipeline cum tool which automates WGS analysis of bacterial genomes to identify Single Nucleotide Polymorphisms (SNPs), kmer frequencies, Mobile Genetic Elements (MGEs), Antibiotic Resistance genes, association between MGEs and ARGs and co-occurrence of MGEs.

It can also perform de novo genome assembly using SPAdes, de novo genome annotation using prokka, and generate visualisations, csv files based on the results from these processes.

What platforms do Bacalyze support?

Bacalyze supports Linux natively, and can run on Mac and Windows using Docker. More details on installation can be found below:
